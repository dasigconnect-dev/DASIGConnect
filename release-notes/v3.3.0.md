# Release Notes - v3.3.0

**Release Date:** 2026-11-05  
**Release Version:** `3.3.0`

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### Added
- **Facebook Page Access Token Eye Reveal & Copy Toggle:** Introduced secure credential visibility controls in **Settings → System Health → Integrations & Tokens**, including a dedicated `PAGE ACCESS TOKEN` column, an eye toggle button (`ti ti-eye` / `ti ti-eye-off`) powered by backend endpoint `GET /api/v1/system-health/tokens/{tokenId}/reveal` (restricted to `ADMIN` and `OWNER`), and one-click clipboard copy with animated visual checkmark feedback (#455).
- **Inline Secret Toggles for Token Management:** Added absolute-positioned inline eye reveal toggles for the manual token entry field ("Set Manually") and page reconnect dialog ("Connect a Different Facebook Page") (#455).
- **Canva-Style Watermark Studio Revamp:** Overhauled `WatermarkCanvasEditor` into an immersive, full-screen creative studio featuring a submission-aligned sticky toolbar, responsive canvas zoom/pan controls, drag-and-drop watermark placement, and per-aspect-ratio configuration persistence (1:1, 4:5, 16:9) (#452).
- **Subscription Billing Master Feature Flag:** Added an application configuration toggle (`app.billing.enabled` / `BILLING_ENABLED`) to gracefully disable commercial billing interactions and checkout redirects during institutional pilot deployment without disrupting core features (#454).

### Fixed
- **Fast-Track Live Event Publishing Disconnect:** Wrapped Fast-Track publishing listeners in `FastTrackPublishingListener` with `@Async` execution, preventing HTTP request thread exhaustion during Meta Graph API dispatch and exponential backoff retries (#455).
- **Silent Fast-Track Publishing Failure Fallback:** Added automatic error fallback handling calling `facebookPublisherService.markFailed(...)` if publishing encounters network or Graph API exceptions during approval or retry, ensuring timely state transitions to `PUBLISH_FAILED` and visibility in the Review Queue Failed tab (#455).
- **Review Queue Panel Collapse State Reset:** Resolved an issue where approving or acting on a submission left collapsed side panel state un-reset, preventing blank layout rendering across review queue items (#453).

### Changed
- **Status Terminology Standardization:** Standardized legacy `"Approved & Scheduled"` status labels to `"Scheduled"` across `ValidationQueueScreen`, `AuditLogService`, and the submission status copy dictionary for cleaner administrative terminology (#455).
- **System Health Token Table Hierarchy:** Refactored the Integrations & Tokens table layout to separate Connected Page metadata and Page Access Token into dedicated, properly proportioned columns (#455).

### Removed
- **Non-Production Development Artifacts:** Sanitized internal agent orchestration directories (`.agent/`, `.claude/`, `.gemini/`), internal documentation drafts (`docs/md/`, `docs/img/`, `docs/README.md`), developer guides (`CLAUDE.md`, `DEPLOY.md`), and offline evaluation suites (`backend/evaluation/`) from the production release branch.
