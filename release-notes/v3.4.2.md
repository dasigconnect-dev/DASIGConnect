# Release Notes - v3.4.2

**Release Date:** 2026-11-23  
**Release Version:** `3.4.2`

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### Added
- **Per-Row Institution Selector in Bulk Invitations:** Redesigned the bulk invite composer (`InvitationComposer`, `UserManagementScreen`, `UserInvitationsScreen`) with per-row institution selection and case-insensitive institution code lookup (`InstitutionRepository.findByCodeIgnoreCase`) in `InvitationService.previewBatch()` (#485).
- **Missed Schedule Status Badge:** Added dedicated `Missed Schedule` status badge (`ti-calendar-off` / `pill-missed`) and icon handling across `DashboardScreen`, `RecentActivityScreen`, and submission utilities, with clearer guidance copy for `missed_review` (#486).

### Fixed
- **Bulk Invite Domain Mismatch Soft Warning:** Updated `InvitationService.previewBatch()` and `sendBatch()` so institution email domain mismatches are treated as a sendable soft warning (`domain_mismatch`) rather than blocking the row as `invalid_email` (#485).

### Changed
- **BrandedSelect Dropdowns & UI/UX Polish:** Replaced native `<select>` elements with `BrandedSelect` across `UploadModal`, `MediaRepositoryScreen`, `AssetDetailPanel`, and `AiCaptionPromptDialog` (with tone icons), polished submission validation styling, removed redundant institution logo watermarks on album cards, and refined the Invite User modal layout (#486).

### Removed
- **Non-Production Development Artifacts:** Sanitized internal agent orchestration directories (`.agent/`, `.claude/`, `.gemini/`), internal documentation drafts (`docs/01-refactoring/`, `docs/03-testing/`, `docs/img/`, `docs/md/`, `docs/tsv/`, `docs/README.md`), developer guides (`CLAUDE.md`, `DEPLOY.md`), and offline evaluation suites (`backend/evaluation/`) from the production release branch.
