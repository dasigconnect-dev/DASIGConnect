# Release Notes - v3.4.0

**Release Date:** 2026-11-13  
**Release Version:** `3.4.0`

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### Added
- **Claude Primary AI Provider & Gemini Hot-Standby Fallback:** Configured `ClaudeVisionClient` (`claude-haiku-4-5-20251001`) as the primary multimodal vision provider in `DelegatingAiVisionClient`, with automatic failover to `GeminiVisionClient` (`gemini-2.5-flash`) on HTTP 400/402 credit exhaustion or network timeouts (#469).
- **Session AI Token & Estimated Spend Tracking:** Added live session token usage and estimated USD spend (`~$X.XXX`, calculated using Claude 3.5 Haiku input/output rates) prominently inside the Claude AI card on the System Health dashboard (#469).
- **Voyage AI Service Card:** Integrated Voyage AI (`voyage-multimodal-3`) into the 3-column AI Services monitoring grid on System Health (#469).
- **Dynamic Facebook Page Name Resolution:** Added `pageName` resolution in `TokenManagementService` via Meta Graph API (`/{page-id}?fields=name`) with configurable fallback (`app.facebook.page-name`), displaying the human-readable Page name (`DASIG Central Visayas`) alongside the Page ID (#469).
- **Concurrent "Run All Jobs" Maintenance Toolbar:** Added a mobile-responsive sticky toolbar in System Health allowing administrators to trigger all background maintenance jobs concurrently without UI blocking (#469).
- **Facebook Post Preview Collage & Media Selection Enhancements:** Added multi-image collage rendering in the Facebook post preview and streamlined media attachment deselection (#461).

### Fixed
- **System Health Quota & Progress Meter Accuracy:** Removed misleading rate-limit percentage bars for prepaid Claude accounts, fixed progress meter fill styling for healthy metrics, and title-cased job filter pills (`All`, `Healthy`, `Stale`, `Failed`) (#469).
- **Watermark Studio Overlay Controls & Anchor Persistence:** Improved studio overlay controls, added custom color picker support, fixed anchor persistence across aspect ratios, and addressed watermark image quality (#465, #468).
- **Unified AI Caption Flow & Prompt Dialog:** Unified the AI caption generation flow, redesigned the prompt dialog, and refined Facebook caption generation prompts (#466).
- **Submission Composer Autosave & Preview Polish:** Made draft autosave non-disruptive and polished inline tags, schedule availability suggestions, and preview layout (#467).
- **Calendar Toolbar & Media Library Dropdown Clipping:** Resolved calendar toolbar collisions, improved responsive metrics layout, fixed media library dropdown clipping, and aligned asset card selection highlights (#461, #462).

### Changed
- **AI Service Grid & Card Hierarchy:** Reorganized AI services into a balanced 3-column responsive grid (`Claude AI`, `Gemini AI`, `Voyage AI`), displaying clear `Primary AI`, `Backup AI`, and `Media Search` role tags (#469).

### Removed
- **Non-Production Development Artifacts:** Sanitized internal agent orchestration directories (`.agent/`, `.claude/`, `.gemini/`), internal documentation drafts (`docs/md/`, `docs/img/`, `docs/README.md`), developer guides (`CLAUDE.md`, `DEPLOY.md`), and offline evaluation suites (`backend/evaluation/`) from the production release branch.
