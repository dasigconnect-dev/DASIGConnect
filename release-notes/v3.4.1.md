# Release Notes - v3.4.1

**Release Date:** 2026-11-22  
**Release Version:** `3.4.1`

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### Added
- **Review Queue Sort Direction Toggle:** Added directional arrow indicators (`↑` / `↓`) and click-to-toggle ascending/descending support for **Publish Slot** and **Submitted** sorting in `ValidationQueueScreen` and `/api/v1/validation/queue/page` (#483).
- **Release Branch CI Enforcement:** Added a GitHub Actions check enforcing that pull requests targeting `main` originate from a `release/*` branch (#482).
- **Paginated Media Pickers & Mobile Watermark Modals:** Added paginated media library pickers with AI suggestion diagnostics (#479) and mobile watermark modals, scroll cues, and unsaved-changes guards (#475).

### Fixed
- **Review Queue Sorting Order:** Fixed `SubmissionRepository.findValidationPage` so Live Event (`fastTrack`) priority applies only when sorting by **Publish Slot** on active tabs, **Submitted** strictly orders by submission timestamp, `NULL` slots sort last, and `Scheduled` defaults to ascending (`↑`) soonest-slot-first (#483).
- **Scheduling Guard Rails & Local Date Hydration:** Enforced guard rails on admin/moderator edits and alternative slot suggestions, blocked selecting past times on today's date in `TimePickerField`, added `.is-invalid` red glow feedback on required inputs, and fixed UTC-vs-local date shifting when reopening early-morning scheduled submissions (#483).
- **Media Semantic Search & Album Auto-Matching:** Enforced cosine similarity thresholds (`MIN_SEMANTIC_SIMILARITY = 0.40`, `MAX_SEMANTIC_SCORE_DROP = 0.12`) in `MediaAssetService.semanticSearch()`, filtered low-relevance embedding scores, and excluded generic filename stopwords/short tokens during album auto-matching (#483).
- **Draft Autosave & Media Caching:** Smoothed initial draft autosave so the composer stays mounted during background media uploads and cached media library/suggestion queries (#481).
- **Submission & Preview UI Refinements:** Replaced the inline submission card status callout box with a hover/focus tooltip on the status badge, improved the Facebook preview header and carousel controls, and enriched `CalendarEventDetailModal` metadata (#483).
- **Dashboard Recent Activity & Next-Action CTA:** Updated Recent Activity to display and sort by `Last Activity` (`updatedAt ?? publishedAt ?? submittedAt ?? createdAt`) and replaced the low-contrast blue-on-blue next-action button with a high-contrast white pill CTA (#483).

### Changed
- **Mobile UI & Picker Polish:** Refined mobile pickers, swipe hints, draft badge, toast contrast, report modal buttons, and scroll spacing (#472, #477).

### Removed
- **Non-Production Development Artifacts:** Sanitized internal agent orchestration directories (`.agent/`, `.claude/`, `.gemini/`), internal documentation drafts (`docs/01-refactoring/`, `docs/03-testing/`, `docs/img/`, `docs/md/`, `docs/tsv/`, `docs/README.md`), developer guides (`CLAUDE.md`, `DEPLOY.md`), and offline evaluation suites (`backend/evaluation/`) from the production release branch.
