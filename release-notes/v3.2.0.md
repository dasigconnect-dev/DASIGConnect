# Release Notes - v3.2.0

**Release Date:** 2026-10-25  
**Release Version:** `3.2.0`

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### Security
- **Authentication Route Redirection Guard:** Added automated client-side routing guards redirecting active authenticated users away from public auth entry routes (`/login`, `/register`, `/forgot-password`, `/reset-password`) directly to their role dashboards, preventing session collisions and unauthorized dual-session states (#450).
- **Post-Settlement Plan Activation Verification:** Enforced strict payment settlement verification in `SubscriptionPaymentSettlementService` and `PaymongoWebhookService` before activating paid subscription tiers, preventing unverified or pre-settlement plan upgrades (#441).

### Fixed
- **Flyway Database Migration Collision (V133):** Renamed duplicate migration `V130__subscription_invoice_target_plan.sql` to `V133__subscription_invoice_target_plan.sql`, resolving startup Flyway migration versioning conflicts and schema checksum collisions (#448).
- **AI Media Suggestion Relevance & Cosine Ranking:** Enhanced semantic similarity scoring, token overlap analysis, and tag weightings in `AIRecommendationService` and `MediaSemanticEmbeddingService`, preventing low-relevance media recommendations (#445).
- **Free Plan Modal Reminder:** Corrected Free plan comparison behavior for paid subscribers and rendered explicit confirmation reminder modals when interacting with default plan boundaries (#441).
- **Frontend Effect & Navigation Lint Rules:** Resolved React effect dependency warnings, lint violations, and navigation hook race conditions across media and subscription screens (#442).

### Changed
- **Subscription Plans Screen Redesign:** Overhauled `SubscriptionPlansScreen` into a dedicated full-screen layout featuring a streamlined sticky topbar, plan toggle tabs, clear tier feature matrices (Free, Pro, Enterprise), and modern card hierarchy (#449).
- **Spring Boot Framework Upgrade to 4.0.8:** Upgraded backend Spring Boot starter parent to version 4.0.8 for updated dependencies, performance optimizations, and security patches (#444).
- **Landing Page Team & Developer Showcase:** Refreshed developer profile cards, responsive accordion gallery displays, and optimized developer portraits on the public landing page (#450).

### Removed
- **Non-Production Development Artifacts:** Removed internal agent orchestration directories (`.agent/`, `.claude/`, `.gemini/`), internal documentation drafts (`docs/md/`, `docs/img/`, `docs/README.md`), root dev guides (`CLAUDE.md`, `DEPLOY.md`), and offline evaluation harnesses (`backend/evaluation/`) from the production release branch.
- **Backend Field-Level Injection (`@Autowired`):** Eliminated optional and field-level annotations in favor of constructor injection across core Spring services (`AuditLogService`, `ContentIdeaSuggestionService`, `InstitutionService`, `InvitationService`, `MediaAssetService`, `SubmissionService`, `UserService`, `NotificationEventListener`) (#443).

### Added
- **Structured Media Metadata Contract v2 (Gemini Vision):** Implemented schema migration `V132__structured_media_metadata_contract.sql`, `MediaMetadataTaxonomy`, and strengthened `GeminiVisionClient` to extract structured visual taxonomy, categories, tags, sentiment, and OCR text (#442).
- **Pending Admin Ownership Transfer Sidebar Badge:** Added an interactive arrow-up visual badge indicator to the dashboard sidebar layout alerting administrators of outstanding organization ownership transfers (#447).
- **Blinded Media Suggestion Evaluation Pool:** Introduced `MediaSuggestionEvaluationRunner` and evaluation candidate pool dataset structures for automated offline quality and relevance benchmarking (#446).
