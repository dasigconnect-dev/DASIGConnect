# Release Notes - v3.4.3

**Release Date:** 2026-11-24  
**Release Version:** `3.4.3`

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### Added
- **Expanded Validation Task Telemetry:** Extended `useTaskTelemetry` (`roleTaskName`, `ensureStarted`, `recordError(count)`, `rearmAfterComplete`) and added `usePageViewTelemetry` (dwell ≥ `1000ms`) to capture time-on-task, error counts, and first-attempt completion across Dashboard next-action CTAs, Bulk CSV invitations (`InvitationComposer`), Institution Management (`InstitutionManagementScreen`), Failed-Publication Recovery (`useResolutionFailures`), Submission validation/upload errors (`SubmissionScreen`), and view-only screens (`AnalyticsDashboardPage`, `SystemHealthScreen`, `CalendarScreen`, `AuditLogScreen`) (#488).
- **Plain Retry Audit Trail:** Recorded `MANUAL_PUBLISH_RETRY` in `ManualPublishingService.retry()` attributed to the acting user so plain retries leave an auditable record alongside override retries (#488).
- **Automated Regression Suites:** Added `InstitutionServiceAuditAttributionTest`, retry-audit coverage in `ManualPublishingServiceTest`, media-tag truncation/deduplication coverage in `SubmissionServiceTest`, and Playwright E2E suite `frontend/e2e/validation-telemetry.spec.ts` (#488, #489).

### Fixed
- **Long Event Title Submission Failure (50-Char Media Tag Limit):** Fixed a bug where event titles longer than 50 characters failed on submit with HTTP 409 `"Duplicate or invalid data"` because the auto-synced default media tag exceeded `asset_tags.label` (`VARCHAR(50)`). Capped media tags to 50 characters and deduplicated repeated labels in `SubmissionService.applySubmissionMediaTags()` and `normalizeMediaTag()` (`utils.ts`), and kept auto-synced title tags aligned in `SubmissionScreen.tsx` (#489).
- **Institution Audit Log Actor Attribution:** Fixed `InstitutionService` so `INSTITUTION_CREATED`, `INSTITUTION_UPDATED`, `INSTITUTION_DEACTIVATED`, and `INSTITUTION_REACTIVATED` audit entries are attributed to the authenticated Administrator via `auditLogService.recordByActorId()` instead of anonymous system entries (#488).

### Changed
- **Actionable Data Integrity Error Messages:** Updated `GlobalExceptionHandler.handleDataIntegrity()` to log the root cause and return specific, user-friendly 409 messages for field-length violations, publishing slot collisions, and duplicate records instead of the generic `"Duplicate or invalid data"` string (#489).

### Removed
- **Non-Production Development Artifacts:** Sanitized internal agent orchestration directories (`.agent/`, `.claude/`, `.gemini/`), internal documentation drafts (`docs/01-refactoring/`, `docs/03-testing/`, `docs/img/`, `docs/md/`, `docs/tsv/`, `docs/README.md`), developer guides (`CLAUDE.md`, `DEPLOY.md`), and offline evaluation suites (`backend/evaluation/`) from the production release branch.
